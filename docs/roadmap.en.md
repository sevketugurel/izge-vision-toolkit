# Roadmap (English summary)

Detailed Turkish roadmap: [ROADMAP.md](ROADMAP.md). Nothing below is a commitment or a date.

## Near term
- Green CI on GitHub for every job; keep `main` current with `develop`.
- English translation of the main design documents.
- Port the frontend motion-token guard tests into the main test suite.
- Pin Hugging Face model revisions in code.

## Next
- A small, consented, human-labelled validation set, published with labelling instructions and agreement statistics.
- First honest accuracy numbers (with confidence intervals and failure examples) for detection counts and feeding-state classification.
- Cross-check the MOT scorer against an established reference implementation on the same files.
- Real user accounts and authorization before any networked deployment is encouraged.

## Later, only if validated
- Animal re-identification across cameras.
- Additional behaviours with suitable cameras and labels.
- Edge inference on low-power hardware.

## Out of scope
Disease, estrus or lameness diagnosis.
