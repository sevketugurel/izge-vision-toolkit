# Support

- **Bugs and feature requests:** open a GitHub issue using the templates. Include the commit hash and exact commands.
- **Security problems:** see [SECURITY.md](SECURITY.md); do not use public issues.
- **Usage questions:** open an issue labelled `question` after reading the README and `docs/`.

This is a small research project maintained in spare time. There is no SLA and no commercial support. Most deep documentation is currently in Turkish; English questions are welcome.
